# The Burning Wheel — Information Library

This folder is the GitHub home for the research material that previously lived in a Google Notebook. It exists to support the development of **The Burning Wheel** persona — a "biblically accurate angel" AI personality built on apophatic theology, higher-dimensional geometry, consciousness studies, fractal mathematics, and cosmic-scale comedy.

## How this library is organized

The 262 sources from the original notebook bibliography have been de-duplicated, verified where possible, and sorted into thematic sections. Each section document contains:

1. **An orientation** — what the section is about and how it feeds the persona.
2. **Annotated sources** — every source from the bibliography that belongs in the section, with its original notebook number, a short annotation, and a credibility tag.

## Credibility tags used throughout

- **[peer-reviewed]** — journal article or academic press
- **[reference]** — encyclopedic overview (SEP, Wikipedia, etc.)
- **[primary text]** — the original mystical/philosophical work itself
- **[popular]** — videos, blogs, Reddit, journalism
- **[fringe]** — non-mainstream or speculative science; useful as persona flavor, not as established fact
- **[unverified]** — could not be identified or located

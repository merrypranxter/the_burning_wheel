# 05 — Fractals, Chaos & Scale Invariance

Self-similarity all the way down (and up). A **fractal** repeats its pattern across scales; **scale invariance** means a system's statistics don't change when you zoom. The startling part is where this shows up for real: heartbeat dynamics, neural signals, river networks, galactic filaments. The persona's "As Above, So Below" module (B) and its cosmological deadpan both draw from here. Distinguish: **fractal physiology is established science; fractal cosmology is speculative; "fractal universe proves God" is persona poetry, not physics.**

Feeds prompt sections: **Your Mathematics**, **Module B (fractals / as above so below)**, **Psychedelic Ontology**.

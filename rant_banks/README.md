# Rant banks

Permanent source-grounded seed banks for The Burning Wheel live here.

Recommended naming:
- `notebook-main.md`
- `theology.md`
- `science-weirdness.md`
- `culture-and-category-errors.md`

Use a line containing only `---` between complete seed packets so the web churner can split the bank correctly.

The web app may cache used-seed history in browser localStorage, but this folder is the permanent source of truth for the seed text.
